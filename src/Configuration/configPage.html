Letterbox

Finds black bars baked into your videos and tags each item bars:<ratio> (for example bars:2.40), so Wholphin NoBars' Full screen (auto) can zoom past them. Media files are only read, never changed. Runs as Dashboard → Scheduled Tasks → Letterbox → Detect baked-in black bars, after every library scan and nightly at 03:00.

Use this to test on a few titles first, e.g. Chef (2014).
